# TRADRS Predictions Markets Algo

Desktop app for automated trading on prediction markets.

## Download

Get the latest Windows installer from the **[Releases page](https://github.com/Andersxnnguyen/TRADRS-Predictions-Markets-Algo/releases/latest)**: download `TRADRS-Setup-<version>.exe` and run it.

Once installed, the app updates itself automatically. Each release's notes describe what changed.

## Support

Visit [tradrs.com](https://www.tradrs.com) for help and account questions.
